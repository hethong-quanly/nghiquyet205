Mở rộng kết nối API trực tiếp từ trình duyệt
Cấu hình khóa kết nối: (Khóa được lưu bảo mật cục bộ trên thiết bị của bạn)
Chưa cấu hình API Key. Hãy đăng ký một khóa miễn phí để bắt đầu chat tự do.
Chào đồng chí! Đây là phân hệ Trợ lý AI Mở rộng. Phân hệ này cho phép đồng chí hỏi các câu hỏi chung, kiến thức xã hội, hoặc soạn văn bản, làm thơ giải trí bằng cách kết nối trực tiếp tới mô hình trí tuệ nhân tạo thông qua mã API của bạn.

Mẹo: Sau khi dán API Key và bấm "Lưu Khóa", đồng chí có thể hỏi bất kỳ vấn đề gì một cách hoàn toàn tự do!
